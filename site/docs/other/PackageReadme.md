`Create & Fake` is a test support library, developed by humans, that makes robust testing easy by handling all manners of data generation, mocking, comparisons, validation and even automated requirement-based testing. Designed to handle the bulk of test setup quickly and easily so that developers can focus on the behavior to test, making tests easier to develop and maintain.

Visit the [documentation site](https://werecodent.github.io/CreateAndFake/) for more information and how to get started.
